
## Problem: Reverse a String (Easy)

**Link:** https://leetcode.com/problems/reverse-string/

### Approach
I used the two-pointer technique to reverse the string.
One pointer starts from the beginning and another
starts from the end. I swapped the characters until
both pointers meet.

### Complexity
- Time: O(n)
- Space: O(1)

### Notes
I learned how to reverse a character array using
the two-pointer technique without using extra space.
