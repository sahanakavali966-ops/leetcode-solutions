
## Problem: Valid Anagram (Easy)

**Link:** https://leetcode.com/problems/valid-anagram/

### Approach
I used a character frequency counting method.
I counted the frequency of each character in the
first string and decreased the count for each
character in the second string. If all counts are
zero, both strings are anagrams.

### Complexity
- Time: O(n)
- Space: O(1)

### Notes
I learned how to compare two strings using
character frequency counting.
