
## Problem: Valid Parentheses (Easy)

**Link:** https://leetcode.com/problems/valid-parentheses/

### Approach
I used a stack data structure to check whether
the brackets are correctly opened and closed.
I pushed opening brackets into the stack and
checked whether each closing bracket matched
the top element of the stack.

### Complexity
- Time: O(n)
- Space: O(n)

### Notes
I learned how to use a stack to check matching
brackets and validate parentheses.
